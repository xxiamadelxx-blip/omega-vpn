## M1. Выбор открытого VPN-ядра и Android build-spike — CRITICAL

- [ ] Установить стек Android-проекта, проверить доступность Android SDK/Gradle/JDK в облаке; создать минимальное приложение.
- [ ] Сравнить **v2rayNG/Xray** и **Android sing-box**: лицензии, бинарные API, arm64-v8a, Android 15, внедрение TUN/VpnService.
- [ ] Зафиксировать точные версии зависимостей и лицензии, приложить notices и правила публикации исходников.
- [ ] Выбрать одну основу, оформить `docs/ADR-CORE.md`; не переносить код Happ.
- [ ] `./gradlew assembleDebug` с чистого клона собирает APK; CI запускает сборку.
**Gate M1:** воспроизводимый APK и осознанно выбранный движок без платных API. В этот момент VPN ещё может не работать.

## M2. Вертикальный срез настоящего VPN — CRITICAL

- [ ] Android `VpnService`, системный диалог согласия и foreground-уведомление.
- [ ] Приём одной локально импортированной **разрешённой** VLESS + TLS/Reality конфигурации.
- [ ] Запуск ядра из приложения, обмен пакетами через Android TUN, остановка, корректное освобождение ресурсов.
- [ ] Ошибки подключения/отзыва permission/аварийного закрытия честно видны в UI.
- [ ] На физическом Android получить HTTPS-ответ через VPN и **изменённый публичный IP**. Не достаточно localhost SOCKS в облаке.
**Gate M2:** на OnePlus Nord 3 один настоящий VLESS/Reality-узел работает как **VPN всей системы**, а не прокси одного процесса. Если физический тест недоступен, gate остаётся открытым.

## M3. Полностью бесплатные источники — CRITICAL

- [ ] Подписка HTTP(S): скачать с тайм-аутом и ограничением размера, валидировать, декодировать, дедуплицировать `vless://` и стандартный base64-формат.
- [ ] Сохранить у источника URL, дату последнего обновления, статус; показать согласие пользователя на получение списка.
- [ ] Поддерживать **как минимум один подтверждённо разрешённый открытый источник**, без регистрации/карты/платной подписки. Публичный feed из исследования — только исходный кандидат для оценки.
- [ ] Реальные проверки подключений через ядро; отличать TCP «порт открыт» от HTTPS через туннель.
- [ ] При недоступности узла переключаться на другой совместимый доступный узел; избегать бесконечных циклов.
- [ ] Импорт пользовательской подписки Capybara/Panther допускается **без обхода оплаты/лимитов**. Не считать это условием MVP.
- [ ] При отсутствии бесплатных работающих узлов честно сообщать об этом; никогда не направлять трафик тихо в прямой режим, объявляя его VPN.
**Gate M3:** пользователь без оплаты и учётной записи обновляет разрешённую открытую подписку и получает рабочее VPN-подключение на телефоне.

## M4. Надёжность, безопасность, UX-минимум — HIGH

- [ ] Одна кнопка: connect/disconnect, понятное состояние и ошибка, кнопка обновления.
- [ ] Смена Wi-Fi ↔ mobile, airplane mode/reconnect, отмена подключения, закрытие/перезапуск приложения.
- [ ] DNS через ожидаемый канал; IPv6 либо защищённо маршрутизируется, либо явно отключён с предупреждением. Подтверждение внешними проверками.
- [ ] Ограничения логирования/кэша; не отправлять приватные ключи на стороннюю аналитику, не записывать их в crash-report.
- [ ] TLS verification включена; неизвестные узлы помечены как недоверенные; пользователь видит источник и риски.
- [ ] Ошибочный feed/невалидный ключ не приводит к крашу; отказ разрешения VPN безопасно обрабатывается.
- [ ] Unit/instrumented тесты жизненного цикла, парсера, негативных сценариев.
**Gate M4:** все P0 сценарии автоматизированы там, где это возможно, и подтверждены ручными Android-тестами.

## M5. Приёмка MVP — HARD RELEASE GATE

**Не помечать пройденным, пока каждый обязательный критерий ниже не подтверждён на устройстве.**

| № | Условие выпуска | Как проверить | Результат |
| --- | --- | --- | --- |
| A1 | Бесплатность для пользователя | Новый пользователь без аккаунта/карты/API/VPS получает HTTPS через бесплатный узел; внутри APK нет paywall/рекламы | NOT RUN |
| A2 | Установка на OnePlus Nord 3, Android 15 | Подписанный или debug APK устанавливается, открывается без root и ошибок | NOT RUN |
| A3 | Настоящий Android VPN | Android показывает VPN-статус; браузер/другое приложение маршрутизируется через TUN | NOT RUN |
| A4 | Проверяемая смена IP | Снять прямой IP, включить VPN, сравнить egress IP; IP отличается; HTTPS 200 | NOT RUN |
| A5 | Wi-Fi и мобильная сеть | Повторить A3–A4 в **обеих** сетях (узлы могут различаться) | NOT RUN |
| A6 | DNS и IPv6 | Проверить резолверы, IPv6, отсутствие незаметного обхода при обрыве туннеля | NOT RUN |
| A7 | 30 минут реального трафика | 30 минут HTTPS/видео/обычного использования без неконтролируемого разрыва; зафиксировать наблюдения | NOT RUN |
| A8 | Выключение и возврат сети | Disconnect/отзыв VPN, потеря сети, перезапуск приложения не оставляют сломанный или ложный туннель | NOT RUN |
| A9 | Бесплатные подписки | Открытая подписка загружается/обновляется и позволяет выбрать рабочий узел без платных провайдеров | NOT RUN |
| A10 | Законность/сборка | Лицензии/NOTICE учтены; `./gradlew assembleDebug` и CI успешны, секретов нет | NOT RUN |

**MVP PASS = 10/10 PASS** с датой, версией APK, моделью, Android version, оператором (без личных данных), названием теста, кратким логом/скрином без секретов и коммитом в `docs/evidence/mvp/`. Если хоть одно обязательное условие `FAIL` / `NOT RUN` — **MVP FAIL/INCOMPLETE**. «Один публичный прокси из облака работает» != MVP.

Внешние зависимости: физический телефон и хотя бы одна разрешённая бесплатная подписка, работающая в проверяемой сети. Нельзя гарантировать их доступность заранее.

## Метрика успеха

**Не число скачанных конфигураций, а число успешных VPN-сессий на настоящем телефоне без оплаты**, с подтверждёнными IP/DNS/HTTPS-тестами. Счётчик найденных серверов не является метрикой доступности.

## Учёт выполнения агентами

При закрытии каждого gate в соответствующей секции добавить:
`Дата | commit SHA | окружение | команды / результаты | ссылка на безопасные артефакты | ограничения`.
Не удалять отрицательные результаты: именно они определяют следующую гипотезу и предотвращают повторение ошибок.
