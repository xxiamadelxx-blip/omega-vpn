# Ω VPN (Omega VPN)

**Статус:** M1 завершён, **M2 в работе**, сделан ранний срез M3: Ω VPN сам скачивает бесплатные конфигурации VLESS/Reality по кнопке. Xray AAR и Android VpnService собираются в APK. **На телефоне трафик через VPN пока не проверен, M2 НЕ ЗАКРЫТ.**  
**Дата старта:** 2026-10-08. **Основной язык документации:** русский.

> Цель: собственный Android VPN-клиент, который подключается к **разрешённым бесплатным** VPN-узлам без платной подписки, обязательной регистрации, собственного VPS и платных API. Факт бесплатности клиента не означает гарантированного наличия бесплатного трафика.

## Суть

Omega VPN — Android-приложение с одной кнопкой подключения, выбором рабочего узла и обновлением публичных подписок. В первом релизе нужен **проверенный VPN-туннель**, а не просто каталог «серверов» с красивой кнопкой. Проект вдохновлён пользовательским сценарием Happ; **не является модификацией закрытого APK Happ и не копирует его код/ресурсы**.

**MVP для конкретного устройства:** OnePlus Nord 3, Android 15. Проверка Wi-Fi и мобильного интернета обязательна.

## Безопасность публичного каталога

**Публичные бесплатные VPN-узлы являются недоверенными.** Наличие рабочего VLESS/Reality-туннеля не доказывает личность оператора, отсутствие наблюдения за трафиком или его связь/несвязь со спецслужбами. Мы не выявили доказательств конкретной принадлежности узлов ФСБ, но и исключить её по публичному каталогу нельзя.

В версии после [security commit c6c56c5](https://github.com/xxiamadelxx-blip/omega-vpn/commit/c6c56c5ce344ca59ade4f7dbcb5545cd1d0587e5) поиск серверов **не включает VPN автоматически**: перед первым подключением нужно отдельно подтвердить ознакомление с риском и нажать «Подключиться». Отбор публичного списка принимает только корректные публичные IPv4-адреса, отбрасывая доменные имена (защита от части DNS-rebinding), localhost, внутренние, служебные, CGNAT, документационные и другие недоступные для публичного VPN адреса. Часть нормальных узлов будет отфильтрована. Отключён cleartext-трафик для сетевого стека самого Android-приложения; это **не** запрещает HTTP в других приложениях, работающих через VPN.

**Особенно важно:** приложение скачивает каталог напрямую через GitHub, поэтому GitHub/CDN получает IP пользователя; затем реальный IP увидит выбранный VPN-оператор. При высоком риске идентификации/слежки нельзя считать анонимный публичный узел достаточной защитой. Подробнее: [модель угроз и план аудита](docs/SECURITY_THREAT_MODEL.md). M2/M5 не закрыты до проверки реального трафика, DNS и IPv6.

## Без ручного поиска ключей (версия 0.2.1-auto-free)

Теперь первый экран предлагает **«Найти бесплатный VPN»**. Эта кнопка только загружает каталог, но не запускает туннель. Для подключения нужно отдельное подтверждение риска и нажатие «Подключиться». По нажатию приложение скачивает публичный HTTPS-каталог [Au1rxx/free-vpn-subscriptions](https://github.com/Au1rxx/free-vpn-subscriptions), декодирует Base64, выбирает до 120 подходящих конфигураций **VLESS/TCP/Reality**, исключает дубликаты и предлагает включить VPN через стандартное разрешение Android.

Если первый узел не подходит, есть **«Попробовать другой сервер»** и **«Обновить бесплатные серверы»**. Регистрация, платные API, копирование ключа и собственный VPS не требуются. Конфигурации не сохраняются на диск. Подробный протокол: [автоматический поиск](docs/evidence/AUTO_DISCOVERY_2026-10-08.md).

**Предупреждение:** каталоги и неизвестные операторы VPN-узлов не гарантируют приватность, законность доступа или доступность на конкретном операторе. Сейчас ещё нет автоматической проверки реального HTTPS по каждому узлу и бесшовного failover. **Это не пройденный M2/MVP.**

## Обязательный MVP

1. Устанавливается и запускается на OnePlus Nord 3 (Android 15), без root.
2. Получает и корректно валидирует хотя бы один **легально доступный бесплатный** источник стандартных подписок; поддерживает VLESS + TLS/Reality. Пользователь видит источник/время обновления.
3. Подключается через Android `VpnService` к **реально работающему бесплатному** серверу, а не к тестовому mock.
4. Во время активного VPN показывает подключённый статус, позволяет отключиться и корректно обрабатывает отзыв разрешения Android.
5. Проверяемо меняет публичный IP, пропускает HTTPS и выполняет проверку DNS/IPv6-маршрутов без утечек, с явно описанными ограничениями.
6. Проверен **на устройстве** по Wi-Fi и мобильной сети, включая переподключение и 30 минут непрерывной работы.
7. Не требует оплаты, пробной подписки с привязанной картой, платного API, отдельного сервера, регистрации или просмотра рекламы для работы базового режима.
8. Не содержит приватных ключей в репозитории и не отправляет их в телеметрию; список источников и условия работы видимы.

**Точный release gate и тест-протокол:** [MILESTONES.md](MILESTONES.md). Без положительных результатов на реальном Android статус проекта **не «MVP готов»**.

## Техническое направление

- **Android:** Kotlin, Jetpack Compose, минимальные зависимости и разрешения, `VpnService` с foreground service/уведомлением по правилам целевой Android API.
- **VPN-движок:** предпочтительно переиспользовать проверенный open-source Android-клиент/ядро Xray (например, [v2rayNG](https://github.com/2dust/v2rayNG)) с проверкой лицензий и совместимости; не переписывать криптографию и протоколы самостоятельно. Альтернатива: совместимый мобильный sing-box, только после spike сборки.
- **Первый протокол:** VLESS/Reality. Остальные — после подтверждённого MVP.
- **Конфигурации:** стандартные `vless://` и подписки, без доступа к закрытым API поставщиков.
- **Поставщики CapybaraVPN / Panther:** только как обычные подписки/ссылки, если пользователь имеет право на доступ; **не обходить оплату, авторизацию, лимиты или trial**.
- **Источники:** перечень с возможностью отключить ненадёжный/отозванный; тестировать через реальный туннель и ограничивать скорость запросов.
- **Безопасность:** не отключать проверку TLS-сертификата ради подключения; не обещать приватность на неизвестных узлах, предупреждать о доверии оператору узла; без скрытого сбора логов трафика.

## Принципы разработки

Результат фиксируется **коммитами в этом репозитории**, а не только сообщениями в чате. Не считать проверку из немецкого Vercel Sandbox заменой проверки мобильной сети в Санкт-Петербурге. Не требовать от пользователя локального ПК, если сборка возможна в облачном CI; физический телефон может понадобиться только для реальной Android-приёмки. Изменять существующую функциональность по одному проверяемому шагу и не усложнять MVP механизмами рекомендаций, большим каталогом стран или собственной облачной инфраструктурой.

## Сборка и проверка M1

В репозитории есть настоящий Android-проект с идентификатором `dev.omega.vpn`, `minSdk 26`, `targetSdk 35`, Gradle Wrapper 8.13, Kotlin 2.1.20 и Jetpack Compose. На чистой машине с JDK 21 и Android SDK 35:

```bash
./gradlew --no-daemon :app:assembleDebug :app:testDebugUnitTest
```

Выходной APK: `app/build/outputs/apk/debug/app-debug.apk`. Автоматически собирается также через [GitHub Actions](https://github.com/xxiamadelxx-blip/omega-vpn/actions/workflows/android-ci.yml). В успешном [запуске M1](https://github.com/xxiamadelxx-blip/omega-vpn/actions/runs/37804978821) опубликован отладочный APK в `omega-vpn-m1-debug` (временный Actions-артефакт, доступ может требовать GitHub-авторизации). После 7 дней он удаляется согласно настройкам CI.

**M2-APK:** есть экспериментальный интерфейс VLESS/Reality, кнопка запуска и нативный Xray. Библиотека собирается командой `bash scripts/build-xray-android.sh` после установки Go 1.27.2, Android SDK 35 и NDK r28; далее выполняется `./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug`. В GitHub Actions эти шаги автоматизированы. **Никакой гарантии подключения/смены IP до тестирования на физическом Android нет.** Автоматический подбор бесплатных подписок относится к M3. Полный отчёт: [M1_BUILD_2026-10-08.md](docs/evidence/M1_BUILD_2026-10-08.md). Лицензии и обязательства по будущему ядру: [THIRD_PARTY_NOTICES.md](docs/THIRD_PARTY_NOTICES.md).

## Как проверить экспериментальный M2 APK на телефоне

Получить ZIP-артефакт `omega-vpn-m2-debug` из [GitHub Actions](https://github.com/xxiamadelxx-blip/omega-vpn/actions/workflows/android-ci.yml) успешной M2-сборки (при скачивании может понадобиться вход в GitHub), извлечь APK, установить на Android 15, открыть и вставить **законно полученный VLESS/TCP/Reality ключ**. Нажать «Подключить», подтвердить системный VPN-запрос. Состояние «Xray запущен» само по себе не доказывает прохождение трафика. Проверить внешнюю IP-адресацию, HTTPS, DNS и IPv6 на Wi-Fi и мобильной сети. Полный [M2 протокол](docs/evidence/M2_NATIVE_BUILD_2026-10-08.md). Не используйте публичные неизвестные узлы для чувствительных данных.
