# Ω VPN (Omega VPN)

**Статус:** проект и спецификация MVP; Android-приложение пока **не реализовано**.  
**Дата старта:** 2026-10-08. **Основной язык документации:** русский.

> Цель: собственный Android VPN-клиент, который подключается к **разрешённым бесплатным** VPN-узлам без платной подписки, обязательной регистрации, собственного VPS и платных API. Факт бесплатности клиента не означает гарантированного наличия бесплатного трафика.

## Суть

Omega VPN — Android-приложение с одной кнопкой подключения, выбором рабочего узла и обновлением публичных подписок. В первом релизе нужен **проверенный VPN-туннель**, а не просто каталог «серверов» с красивой кнопкой. Проект вдохновлён пользовательским сценарием Happ; **не является модификацией закрытого APK Happ и не копирует его код/ресурсы**.

**MVP для конкретного устройства:** OnePlus Nord 3, Android 15. Проверка Wi-Fi и мобильного интернета обязательна.

## Обязательный MVP

1. Устанавливается и запускается на OnePlus Nord 3 (Android 15), без root.
2. Получает и корректно валидирует хотя бы один **легально доступный бесплатный** источник стандартных подписок; поддерживает VLESS + TLS/Reality. Пользователь видит источник/время обновления.
3. Подключается через Android `VpnService` к **реально работающему бесплатному** серверу, а не к тестовому mock.
4. Во время активного VPN показывает подключённый статус, позволяет отключиться и корректно обрабатывает отзыв разрешения Android.
5. Проверяемо меняет публичный IP, пропускает HTTPS и выполняет проверку DNS/IPv6-маршрутов без утечек, с явно описанными ограничениями.
6. Проверен **на устройстве** по Wi-Fi и мобильной сети, включая переподключение и 30 минут непрерывной работы.
7. Не требует оплаты, пробной подписки с привязанной картой, платного API, отдельного сервера, регистрации или просмотра рекламы для работы базового режима.
8. Не содержит приватных ключей в репозитории и не отправляет их в телеметрию; список источников и условия работы видимы.

**Точный release gate и тест-протокол:** [MILESTONES.md](MILESTONES.md). Без положительных результатов на реальном Android статус проекта **не «MVP готов»**.

## Техническое направление

- **Android:** Kotlin, Jetpack Compose, минимальные зависимости и разрешения, `VpnService` с foreground service/уведомлением по правилам целевой Android API.
- **VPN-движок:** предпочтительно переиспользовать проверенный open-source Android-клиент/ядро Xray (например, [v2rayNG](https://github.com/2dust/v2rayNG)) с проверкой лицензий и совместимости; не переписывать криптографию и протоколы самостоятельно. Альтернатива: совместимый мобильный sing-box, только после spike сборки.
- **Первый протокол:** VLESS/Reality. Остальные — после подтверждённого MVP.
- **Конфигурации:** стандартные `vless://` и подписки, без доступа к закрытым API поставщиков.
- **Поставщики CapybaraVPN / Panther:** только как обычные подписки/ссылки, если пользователь имеет право на доступ; **не обходить оплату, авторизацию, лимиты или trial**.
- **Источники:** перечень с возможностью отключить ненадёжный/отозванный; тестировать через реальный туннель и ограничивать скорость запросов.
- **Безопасность:** не отключать проверку TLS-сертификата ради подключения; не обещать приватность на неизвестных узлах, предупреждать о доверии оператору узла; без скрытого сбора логов трафика.

## Принципы разработки

Результат фиксируется **коммитами в этом репозитории**, а не только сообщениями в чате. Не считать проверку из немецкого Vercel Sandbox заменой проверки мобильной сети в Санкт-Петербурге. Не требовать от пользователя локального ПК, если сборка возможна в облачном CI; физический телефон может понадобиться только для реальной Android-приёмки. Изменять существующую функциональность по одному проверяемому шагу и не усложнять MVP механизмами рекомендаций, большим каталогом стран или собственной облачной инфраструктурой.
