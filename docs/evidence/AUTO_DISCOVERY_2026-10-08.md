# Ω VPN: встроенный поиск бесплатных VLESS/Reality ключей

Дата: 2026-10-08. Статус: **сборка/тесты PASS, реальная Android VPN-сессия NOT RUN**.

## Задача
Пользователь не должен самостоятельно искать, копировать или оформлять ключи. Поэтому в версии `0.2.1-auto-free` поле ручного ввода заменено кнопкой **«Найти бесплатный VPN»**.

Теперь приложение по нажатию кнопки загружает открытый список конфигураций, декодирует Base64, принимает только VLESS + TCP + Reality, проверяет UUID/SNI/публичный Reality-ключ/shortId/flow, удаляет дубликаты, ограничивает число до 120 и предлагает подключение через существующий Android VpnService + Xray. Кнопки «Попробовать другой сервер» и «Обновить бесплатные серверы» позволяют обойти недоступный узел. Без обязательной регистрации, карты, платного API или собственного VPS. Конфигурации находятся в памяти и не коммитятся.

Источник: [Au1rxx/free-vpn-subscriptions](https://github.com/Au1rxx/free-vpn-subscriptions) (публичный каталог, репозиторий под лицензией MIT). Endpoint: `https://raw.githubusercontent.com/Au1rxx/free-vpn-subscriptions/main/output/v2ray-base64.txt`. Автор публикует список открыто; это **не гарантия разрешённости, безопасности и доступности каждого отдельного узла**. В приложении указан автор и предупреждение о доверии оператору VPN.

Безопасность загрузки: HTTPS без redirect, тайм-ауты 10/15 секунд, лимит загрузки 1.5 МБ, до 2 млн символов входа, до 5000 строк и 120 узлов. Никакого автоматического запроса до нажатия кнопки пользователя. Нет записи конфигураций на диск, в аналитику или логи.

## Ограничения

**M2 gate не закрыт:** телефон OnePlus Nord 3 ещё не подтвердил Android VpnService/TUN, реальный HTTPS через VPN, изменение IP, работу по мобильной сети/Wi-Fi, DNS/IPv6 и отсутствие утечек.

Каталог предлагает конфигурации, но приложение **ещё не измеряет успешность HTTPS по каждому узлу**, не выбирает гарантированно живой узел по реальному трафику и не переключается автоматически после разрыва. Временная доступность публичных узлов не гарантируется. Эти задачи остаются в M3–M5.
